# Mobil uygulama

Flutter/Dart uygulaması için ayrılan alan. Henüz Flutter projesi oluşturulmadı.

Kurulum sırasında `lib/`, `test/`, `assets/` ve platform klasörleri burada oluşur. Özellik bazlı mimari için `../../docs/FLUTTER_ARCHITECTURE.md` referanstır. Riverpod, GoRouter ve Dio şu an öneridir. Uygulamaya özel testler ve görseller bu uygulamada tutulur.
