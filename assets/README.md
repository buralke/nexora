# Ortak tasarım kaynakları

Marka, tasarım kaynakları ve birden fazla uygulamada kullanılan özgün görseller için ayrılan alan. Nihai marka henüz belirlenmedi.

Kaynak, lisans ve kullanım amacını dosyalarla birlikte belirtin. Kullanıcı yüklemeleri, kişisel fotoğraflar veya uygulamanın ürettiği medya burada tutulmaz. Uygulamaya özel paketlenen varlıklar ilgili uygulamanın içinde kalır.
