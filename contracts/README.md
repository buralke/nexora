# Sistem sözleşmeleri

Makine tarafından doğrulanabilir API/OpenAPI, olay ve ortak veri şemaları için ayrılan alan. Mevcut API taslağı `../docs/API_SPECIFICATION.md` içindedir.

İlk uygulamada sözleşmenin koddan mı yoksa şemadan mı üretileceğini belirleyin ve tek doğruluk kaynağı kullanın. Elle tutulan ikinci bir rakip API tanımı oluşturmayın. Henüz sözleşme dosyası yoktur.
