# Karar kayıtları

Ürün, mimari ve önemli altyapı seçimlerinin gerekçesi burada tutulur. `../templates/decision.md` şablonunu `ADR-NNNN-kisa-baslik.md` adıyla kopyalayın.

Durumlar: Önerildi, Onaylandı, Reddedildi, Yerine yenisi geçti. Onaylayan kişi/talimat ve tarih belirtilmeden öneriyi onaylı kabul etmeyin. Eski karar silinmez; yerine geçen karara bağlanır. Henüz teknoloji onayı kaydı yoktur.
