# Geliştirme görevleri

Çok adımlı işleri `../templates/task.md` ile kaydedin. Görevler prompt, gereksinim, karar ve doğrulama kayıtlarına bağlanır.

Durumlar: Planlandı, Devam ediyor, Bekliyor, Tamamlandı, İptal. Tamamlanma için kabul kriterleri ve doğrulama sonucu bulunmalıdır. Küçük tek adımlı işlerde prompt ve oturum kaydı yeterlidir.
