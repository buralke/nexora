# Prompt deneyleri

Denemeleri `YYYY-MM-DD-NNN-kisa-baslik/` altında saklayın. Her deney amaç, prompt/sürüm, model ve parametreler, sentetik örnekler, kalite ölçütü, ölçülebiliyorsa maliyet ve sonuç içermelidir. Deney promptu kendiliğinden üretim promptu olmaz; kabul edilen sürüm `../runtime/` altında yayımlanır.
