# Uygulama AI promptları

Uygulamanın fal üretimi, sınıflandırma veya içerik kontrolünde çalıştıracağı promptlar burada tutulur. Geliştirme sohbetleri bu alana konmaz.

İlk gerçek entegrasyonda işlev bazlı klasör ve `v001.md` gibi açık sürüm kullanın. Her sürümde amaç, beklenen girdiler, çıktı sözleşmesi, güvenlik sınırları ve değerlendirme bağlantısı belirtin. Çalışan sürümü kod/yapılandırmadan açıkça referanslayın. Kullanılan sürümü AI işlem kaydında izleyin. Henüz runtime promptu oluşturulmadı.
