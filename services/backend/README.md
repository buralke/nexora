# Backend

API, iş kuralları, AI orkestrasyonu, worker, veri erişimi ve migration dosyaları için ayrılan alan. Henüz servis kurulmadı.

Python/FastAPI ve modüler monolit belgelerdeki başlangıç önerisidir. Seçim netleşince `src/`, `tests/` ve `migrations/` burada oluşturulur. Backend ve worker aynı iş alanlarını paylaşabilir; bu klasör ayrımı mikroservis kararı değildir.

Referanslar: `../../docs/BACKEND_ARCHITECTURE.md`, `../../docs/API_SPECIFICATION.md`, `../../docs/DATABASE_SCHEMA.md`.
