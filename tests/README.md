# Sistemler arası testler

Mobil/backend veya birden fazla bileşeni birlikte doğrulayan uçtan uca ve kabul senaryoları için ayrılan alan. Unit, widget ve servis içi entegrasyon testleri ilgili uygulama/servisin `test/` veya `tests/` klasöründe tutulur.

Gerçek kullanıcı verisi kullanılmaz. Henüz test altyapısı yoktur; strateji `../docs/TESTING_STRATEGY.md` içindedir.
